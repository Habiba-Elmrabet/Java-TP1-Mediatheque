# Java TP1 - Médiathèque Management System

##  Description

This project is a Java application developed as part of my Java practical coursework during my Bachelor's student in applied computer science.

It focuses on Object-Oriented Programming (OOP) concepts through the development of a simple library management system (Médiathèque).

##  Objectives

The main objectives of this project are to practice:

- Interfaces
- Inheritance
- Encapsulation
- Object-Oriented Programming
- Java Packages
- Project organization

##  Technologies

- Java
- Object-Oriented Programming (OOP)

##  Main Components

- **Empruntable:** Interface defining the borrowing behavior.
- **Document:** Base class representing a document.
- **Livre:** Class representing a book.
- **DVD:** Class representing a DVD.
- **Mediatheque:** Service responsible for managing the media library.
- **Main:** Application entry point.

##  Learning Outcomes

Through this project, I practice organizing Java applications using packages and implementing fundamental OOP principles.
